# Changelog

## 1.0.0

- Added balanced candidate-pool v1.1 with PyOD default anchors, stratified
  hyperparameters, and duplicate-free PCA settings.
- Added checksummed ADBench acquisition, dataset/split/evidence identity, and
  exact environment provenance.
- Added frozen normal-only evidence and no-refit custom metric evaluation.
- Added split-level resume, failure-as-worst comparisons, metric runtime, random
  and fixed-default baselines, candidate-budget and domain sensitivity.
- Replaced prevalence subsampling with deterministic class-prior-adjusted AP.
- Added development and confirmation suites with exploratory/confirmatory
  inference semantics.
- Added a single ranked `results.csv`, complete secondary confidence intervals,
  CI, dataset documentation, and contribution guidance.
- Published the complete v1 development and confirmation reference tables.
