# Proposer

You start one experiment. You do not implement or grade it.

**Goal.** A label-free selection rule that generalizes across numeric-only tabular data: one rule, applied the same way to every batch. A rule that branches on dataset identity, size thresholds tuned to particular datasets, or names of sources is out of scope.

1. Before reading `claims/` or `negative.md`, write the mechanism and a discriminating prediction from first principles: what result on the development bank would show the mechanism is wrong.
2. Then read the relevant claims and negative rows. For each, say whether you adopt or reject it and why.
3. Search the literature for the mechanism and record the query and date.
4. Create `research/experiments/<slug>/prediction.md` (250 words) naming the target, the reference and the planned comparison. Commit it.

Prefer an idea that is mechanistically different from the open experiments.
